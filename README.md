# NENP_BiodiversityImpactApp
An app to show the impact of local-scale nature actions (e.g., planting flowers, adding a log pile) on biodiversity.  
File structure is as follows:

NENP_BiodiversityImpactApp/
│
├── app.R
│
├── data/
│   └── biodiversity_data.csv
│
├── R/
│   └── data_preparation.R
│
└── www/
    ├── NENP_logo.svg
    ├── NENP_favicon.ico
    └── cricket-grass.png
